5. Quick Fixes

Common Issues:

  • Image shows "No image found": Social media platforms cache metadata for 24-48 hours. Use the validators above to force a refresh.
  • Image loads slowly: Check your Supabase Storage bucket is in a nearby region.
  • Image doesn't load at all: Verify the Supabase Storage bucket seo-images is set to PUBLIC.
  • Edge function returns 302: Database doesn't have the image URL, or the URL is invalid.
